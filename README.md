# Fibonacci_Factorial_algorithms

A collection of useful Python utility scripts for mathematical and string operations.

## Contents

This repository contains the following Python utilities:

1. **Factorial Calculator** - Calculate the factorial of any positive integer
2. **Ordinal Number Converter** - Convert numbers to their ordinal representation (1st, 2nd, 3rd, etc.)
3. **Fibonacci Generator** - Generate Fibonacci numbers in the sequence

## How to Use

### Factorial Calculator

Calculate the factorial of a positive integer:

```bash
python factorial_calculator.py
```

- Enter a positive integer when prompted
- The program will calculate and display the factorial (n!)
- Type '0' to exit the program

### Ordinal Number Converter

Convert any integer to its ordinal form:

```bash
python ordinal_converter.py
```

- Enter any integer when prompted
- The program will convert it to its ordinal representation (1st, 2nd, 3rd, etc.)

### Fibonacci Generator

Generate numbers in the Fibonacci sequence:

```bash
python fibonacci.py
```

- Enter how many Fibonacci numbers you want to generate
- The program will display the Fibonacci sequence up to that count

## Features

### Factorial Calculator
- Input validation to ensure positive integers
- Efficient iterative calculation
- User-friendly interface

### Ordinal Number Converter
- Handles all edge cases correctly (including teens: 11th, 12th, 13th)
- Works with numbers of any size

### Fibonacci Generator
- Efficiently calculates Fibonacci numbers
